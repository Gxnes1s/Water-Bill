# บัญชี รับ–จ่าย น้ำสวัสดิการ (เว็บแอป)

เว็บแอปสำหรับบันทึกรับ-จ่ายน้ำดื่มสวัสดิการ แทนสมุดจดมือ
- มี 2 แท็บแยกตามขนาดขวด: **350 มล.** และ **600 มล.** — คนละตาราง คนละยอดคงเหลือ แต่เก็บในฐานข้อมูลเดียวกันชื่อ `WaterBill`
- ดูข้อมูลได้ทุกคนที่มีลิงก์ (ไม่ต้องล็อกอิน)
- เพิ่ม / แก้ไข / ลบ รายการได้
- ข้อมูลอัปเดตแบบเรียลไทม์ — ใครแก้ คนอื่นเห็นทันทีโดยไม่ต้องรีเฟรช
- โฮสต์ฟรีบน GitHub Pages, ฐานข้อมูลใช้ Firebase (ฟรี)

## โครงสร้างไฟล์
```
water-ledger/
├── index.html                   ← ตัวเว็บแอปทั้งหมด (หน้าเดียว)
├── firebase-config.example.js   ← ตัวอย่างไฟล์ตั้งค่า (ให้คัดลอกไปทำไฟล์จริง)
└── README.md                    ← ไฟล์นี้
```

---

## ขั้นตอนที่ 1: สร้างฐานข้อมูล Firebase (ฟรี, ใช้เวลา ~5 นาที)

1. ไปที่ https://console.firebase.google.com แล้วล็อกอินด้วย Gmail
2. กด **"Add project" / "สร้างโปรเจกต์"** ตั้งชื่อ เช่น `water-ledger` แล้วกด Create (ปิด Google Analytics ก็ได้ ไม่จำเป็น)
3. เมื่อเข้าหน้าโปรเจกต์แล้ว ที่เมนูซ้าย เลือก **Build > Firestore Database**
4. กด **Create database**
   - เลือกโหมด **"Start in test mode"** (จะแก้กฎความปลอดภัยในขั้นตอนถัดไป)
   - เลือก location เป็น `asia-southeast1 (สิงคโปร์)` หรือใกล้เคียง แล้วกด Enable
5. กลับไปที่หน้าแรกของโปรเจกต์ (รูปเฟือง ⚙️ มุมซ้ายบน > **Project settings**)
6. เลื่อนลงมาที่ **"Your apps"** กดไอคอน **`</>`** (Web) เพื่อสร้างเว็บแอป
   - ตั้งชื่อแอปอะไรก็ได้ เช่น `water-ledger-web` แล้วกด Register app
   - **ไม่ต้อง** ติ๊ก Firebase Hosting
   - จะเห็นโค้ดกล่องหนึ่งหน้าตาแบบนี้:
     ```js
     const firebaseConfig = {
       apiKey: "...",
       authDomain: "...",
       projectId: "...",
       storageBucket: "...",
       messagingSenderId: "...",
       appId: "..."
     };
     ```
   - **คัดลอกค่าทั้งหมดนี้เก็บไว้** จะใช้ในขั้นตอนที่ 2

### ตั้งกฎความปลอดภัย (Firestore Rules)
ที่เมนู Firestore Database > แท็บ **Rules** ให้แก้เป็น:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /WaterBill/{doc} {
      allow read: if true;
      allow write: if true;
    }
  }
}
```

> ชื่อฐานข้อมูล (collection) ที่แอปนี้ใช้คือ **`WaterBill`** — ข้อมูลของขนาด 350 มล. และ 600 มล. เก็บอยู่ใน collection เดียวกัน แต่แยกกันด้วยฟิลด์ `size` ภายใน ไม่ต้องสร้าง collection แยกเอง แอปจะสร้างให้อัตโนมัติเมื่อบันทึกรายการแรก

> หมายเหตุ: กฎนี้เปิดให้ **ใครก็ตามที่มีลิงก์เว็บแก้ไขข้อมูลได้** ซึ่งเหมาะกับการใช้งานภายในทีม/สำนักงานที่ไม่เผยแพร่ลิงก์สาธารณะ
> ถ้าต้องการจำกัดสิทธิ์เฉพาะคนในทีม (ต้องล็อกอินก่อนแก้ไข) แจ้งได้ ผมช่วยเพิ่ม Firebase Authentication ให้ภายหลังได้

กด **Publish** เพื่อบันทึกกฎ

## ขั้นตอนที่ 2: ใส่ค่า Firebase ลงในเว็บแอป

1. คัดลอกไฟล์ `firebase-config.example.js` แล้วเปลี่ยนชื่อเป็น **`firebase-config.js`**
2. เปิดไฟล์ `firebase-config.js` แล้ววางค่าที่คัดลอกจากขั้นตอนที่ 1 แทนของตัวอย่าง เช่น:
   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "AIzaSyxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
     authDomain: "water-ledger-xxxxx.firebaseapp.com",
     projectId: "water-ledger-xxxxx",
     storageBucket: "water-ledger-xxxxx.appspot.com",
     messagingSenderId: "123456789012",
     appId: "1:123456789012:web:abcdef1234567890"
   };
   ```
3. บันทึกไฟล์

---

## ขั้นตอนที่ 3: อัปโหลดขึ้น GitHub และเปิดใช้งาน GitHub Pages

1. ไปที่ https://github.com แล้วสร้าง repository ใหม่ (New repository) เช่นชื่อ `water-ledger` — ตั้งเป็น **Public**
2. อัปโหลดไฟล์ 3 ไฟล์นี้เข้า repository (ลากไฟล์วางในหน้า "Add file > Upload files" ได้เลย):
   - `index.html`
   - `firebase-config.js` (ไฟล์ที่ใส่ค่าจริงแล้วจากขั้นตอนที่ 2)
   - `README.md` (ไม่จำเป็นต้องอัปก็ได้)
3. ไปที่แท็บ **Settings** ของ repository > เมนูซ้ายเลือก **Pages**
4. หัวข้อ **Build and deployment** > Source เลือก **Deploy from a branch**
5. Branch เลือก `main` (หรือ `master`) และโฟลเดอร์เลือก `/ (root)` แล้วกด **Save**
6. รอประมาณ 1-2 นาที แล้วรีเฟรชหน้า Settings > Pages จะเห็นลิงก์เว็บของคุณ เช่น
   ```
   https://ชื่อผู้ใช้.github.io/water-ledger/
   ```
7. เปิดลิงก์นี้ — ควรเห็นตารางบัญชีพร้อมใช้งาน แชร์ลิงก์นี้ให้ทุกคนที่ต้องการดู/บันทึกข้อมูลได้เลย

## วิธีใช้งานเว็บแอป

- **สลับขนาดขวด**: กดแท็บ "ขนาด 350 มล." หรือ "ขนาด 600 มล." ด้านบนตาราง — แต่ละขนาดมีตารางและยอดคงเหลือแยกกัน
- **เพิ่มรายการ**: กดปุ่ม "+ เพิ่มรายการ" มุมซ้ายบน กรอก รับ/เบิก เป็นตัวเลข แล้วเลือก **หน่วย (แพ็ค หรือ ขวด)** ระบบจะคำนวณ **"คงเหลือ" ให้อัตโนมัติ** แยกยอดตามหน่วยที่เลือก (เห็นตัวเลขคงเหลือที่จะได้ก่อนกดบันทึกด้วย) แล้วกด "บันทึกรายการ"
- **รายการใหม่สุดจะอยู่บนสุดของตารางเสมอ** เรียงจากใหม่ไปเก่า
- **แก้ไข**: กดปุ่ม "แก้ไข" ท้ายแถวที่ต้องการ
- **ลบ**: กดปุ่ม "ลบ" ท้ายแถว (มีถามยืนยันก่อนลบ)
- **เรียงลำดับแถว**: ใช้ปุ่ม ↑ ↓ ด้านซ้ายของแต่ละแถวเพื่อสลับลำดับ
- ช่อง **รับ / เบิก** เป็นตัวเลขล้วน (ไม่ใส่หน่วย) พร้อมเลือกหน่วยแยกเป็น **แพ็ค** หรือ **ขวด** — ช่อง **คงเหลือ** ระบบคำนวณให้อัตโนมัติแยกยอดตามหน่วย (คงเหลือแพ็ค กับ คงเหลือขวด นับแยกกันคนละยอด เพราะแปลงหน่วยกันไม่ได้โดยอัตโนมัติ) และถ้าแก้ไขรายการเก่า ยอดคงเหลือของรายการถัดไปทั้งหมดจะคำนวณใหม่ให้ทันที
- ยอด **"คงเหลือล่าสุด"** ที่มุมขวาบนจะดึงจากแถวล่างสุดของตารางเสมอ

## แก้ไขปัญหาที่พบบ่อย

- **หน้าเว็บขึ้น "ยังไม่ได้ตั้งค่า Firebase"** → ตรวจว่าไฟล์ชื่อ `firebase-config.js` (ไม่ใช่ `.example.js`) อยู่โฟลเดอร์เดียวกับ `index.html` และอัปโหลดขึ้น GitHub แล้ว
- **"เชื่อมต่อไม่สำเร็จ: Missing or insufficient permissions"** → กลับไปตั้งค่า Firestore Rules ตามขั้นตอนที่ 1 แล้วกด Publish
- **กดปุ่ม "+ เพิ่มรายการ" แล้วฟอร์มไม่เปิด** → ปัญหานี้แก้แล้วในเวอร์ชันล่าสุด ปุ่มจะเปิดฟอร์มได้เสมอแม้ Firebase ยังเชื่อมต่อไม่สำเร็จ แต่การ "บันทึก" ยังต้องรอให้เชื่อมต่อฐานข้อมูลได้ก่อน (ดูข้อความสถานะด้านบนตาราง)
- **ข้อมูลไม่อัปเดตเรียลไทม์ระหว่างสองเครื่อง** → ตรวจว่าทั้งสองเครื่องเปิดลิงก์ GitHub Pages เดียวกัน (ไม่ใช่เปิดไฟล์ index.html จากในเครื่องโดยตรง)

ต้องการให้เพิ่มระบบล็อกอิน (จำกัดว่าใครแก้ไขได้บ้าง), ปุ่มพิมพ์/ดาวน์โหลดเป็น Excel, หรือกราฟสรุปยอดคงเหลือ แจ้งได้เลยครับ
